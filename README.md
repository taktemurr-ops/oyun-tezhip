# Tezhip · Illumination

Bir dilimi boya, desen dört yana açılsın

Yalnızca açık renkli dilimi boyayabilirsin; simetri boyadığını öbür dilimlere yansıtır. Üstteki hedef deseni eksiksiz oluştur. Sürükleyerek tek fırça darbesiyle birçok kare boyarsın; ne kadar az darbe, o kadar çok yıldız. Silgi zemini geri getirir.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
